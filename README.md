# Aura Design — Interior Design Website Concept

Conceito de site institucional para um estúdio de **design de interiores**, desenvolvido com foco em apresentação sofisticada, narrativa visual e animações durante a navegação.

## Objetivo

Criar uma interface com linguagem mais comercial e editorial, apresentando serviços, processo criativo, portfólio, profissional responsável, depoimentos e contato.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger

## Destaques

- Hero institucional
- Sequência visual do processo de criação
- Portfólio de projetos
- Seção de apresentação profissional
- Depoimentos
- Formulário de contato
- Animações vinculadas ao scroll
- Documentação de design

## Estrutura

```text
.

```

## Aprendizados

O projeto foi uma oportunidade para trabalhar:

- interfaces voltadas a negócios e serviços;
- hierarquia visual e composição editorial;
- transições e animações sutis;
- storytelling de marca;
- organização de conteúdo institucional;
- documentação de decisões de design.
